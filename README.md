# Habit Tracker

This is a simple Habit Tracker application built using **Python** and **Streamlit**.

The application helps users create habits, track their progress, and view their streaks.

## Features

* Add a new habit
* Log habit completion
* View current Target
* Edit and remove habits
* View all habits
* Get motivational information using an API
* Get habit suggestions using an LLM

## Tools Used

* Python
* Streamlit
* Pandas
* CSV
* API
* LLM

## How to Run

Install the required libraries:

pip install streamlit pandas requests openai

Run the application:

streamlit run Habit_Tracker_app.py


## Data

The habit data is stored in a CSV file and managed using Pandas.

The application uses the data to calculate target and completion rates.
